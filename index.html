WorkClock Privacy Policy

Last updated: November 8, 2026 · WorkClock · 工时钟

Overview

WorkClock is a local-first Chrome extension that estimates work time and earnings from the schedule and salary information entered by the user.

Information stored

WorkClock stores the following information locally in Chrome storage:

  • Salary, currency, decimal precision, and work schedule
  • Selected workdays, working hours, and lunch break
  • Language, theme, and amount visibility preferences
  • Local timer state
  • User-initiated settings import and export data

How information is used

The information is used only to calculate and display local work progress, estimated earnings, countdowns, and user preferences inside the WorkClock popup.

Data sharing and transmission

WorkClock does not send stored information to a server. It does not sell, share, or disclose user information to third parties.

WorkClock does not read webpage content, browsing history, keyboard input, mouse activity, account information, or credentials.

WorkClock does not use advertising, analytics, remote code, cloud synchronization, or external APIs.

Permissions

WorkClock requests the Chrome storage permission only. This permission is used to save the preferences and local timer state described above.

Data removal

Users can change or clear WorkClock data through the extension settings or by removing the extension from Chrome.

Contact

For questions about this privacy policy or WorkClock, contact the developer through the support contact shown on the Chrome Web Store listing.
